# 律衡 · 全民法律知识普惠智能体

> 「律衡 — 全民法律知识普惠智能体」。基于团队自研 **LexPilot** 法律智能引擎，把「听得懂的解释 + 有依据的法条 + 可执行的指引」在网页上当场跑起来，面向公众免费开放。

西南民族大学 法学院 · 团队「舞猴」 · 参赛方向：社会公益（教育普惠 / 法律知识普惠）

---

## 这是什么

一个**零依赖、仅约 3MB** 的网页应用（无任何 npm / 构建 / 后端步骤），直接部署到 GitHub Pages 即可访问。打开链接即进入**引擎主页**（问候语界面），在主页上选择身份完成定制；`gate.html` 保留为项目「身份门」展示页，内嵌并同源驱动真引擎——能当场用真的题库判分、真翻法条与案例、真做学习时钟与笔记，而不仅仅是静态页。

设计继承 LexPilot 全套 UI 语言：

- 🎨 设计令牌同源：主色 `#1a5276` / 用户气泡 `#C5DFF8` / 金辉 `#f7b733`，卡片圆角 18px、微信式顶栏、深浅双主题
- 🐋 鲸鱼吉祥物与 `whaleFloat` 浮动动画
- 📱 响应式，移动端直开、适配手机

## 引擎核心功能（对齐项目书 FR-01~FR-10）

- 💬 **AI 法律咨询（FR-01）**：系统提示词按项目书 §3.5 落地——公益普法助手，回答按「结论 / 依据 / 行动 / 边界」结构输出
- 🧭 **领域自动识别（FR-02）**：劳动 / 消费 / 租房 / 借贷 / 交通 / 婚姻 / 刑事七类关键词分流，自动注入领域维权路径与知识库命中
- 🔍 **案情要素引导（FR-03/FR-09）**：事实不清先追问关键要素；单次会话内记住用户补充信息
- 🗺️ **维权路径速查（FR-04）**：六个领域「找谁 / 流程 / 材料清单」+ 12348/12315/12333 等渠道库
- 📄 **文书模板（FR-05）**：借条、起诉状等模板 + AI 要素补全成文
- 📚 **普法案例库（FR-06）**：指导案例分库检索、问答式普法
- ⚖️ **免责与转介（FR-07）**：回答自动附带免责声明；检测到涉刑事情形强制提醒报警 + 12348
- 🌐 **多入口访问（FR-08）**：分享链接、iframe 嵌入、PWA 安装、桌面与移动端响应式
- ❓ **题库练习与判分**：章节练习、考试模式自动判分、错题本（解析免费开放）
- 🕐 **学习工具**：学习时钟（番茄钟）、每日打卡、法条闪卡、法律计算器（借贷利息 / 劳动补偿 / 诉讼费 / 诉讼时效）、笔记

**公益免费**：AI 咨询、题目解析、笔记创建全部免费，无积分、无会员、无任何付费门槛。

## 自动化测试（对位项目书验收标准）

对齐项目书「100+ 大型测试集整体通过率 ≥90%」的验收要求，仓库内置 `tests/` 自动化测试套件：**36 项断言**全部为**纯函数自检**（领域识别 / FAQ 命中 / 免责转介 / 题库判分 / 案例与模板 / 一致性 / Meta），**不依赖大模型与网络**，任意静态服务即可复现，知识库 / 题库 / 模板数据变更后重跑即回归：

```bash
npx serve .      # 或 python -m http.server 8000
# 浏览器打开 http://localhost:8000/tests/run-tests.html
# 通过率横幅（绿 ≥90% / 红 <90%）即结果；亦可用 headless Chrome 断言输出
```

覆盖项（节选）：七领域识别与低置信兜底、FAQ 30+ 条命中与上限、免责声明唯一性、刑事强制转介 110/12348、题库多选判分、案例来源可溯（最高法官方链接）、文书模板 ID 齐备、law.html 与 sw.js 一致（含 **vendor/ 文件真实存在**——防离线样式丢失）。

## 离线与依赖

- **零 CDN**：marked / highlight / mammoth 全部本地化到 `vendor/`，公网不可用时渲染、语法高亮、DOCX 导入依旧可用（NFR-03）
- **离线可用**：`sw.js` v9 安装时预缓存核心页面与 vendor 库，断网后主文档回退缓存、其余 stale-while-revalidate。
- **分享卡片**：页面声明 og:title / og:image，经社交平台 / IM 分享显示规范卡片。

## 法律资源库与自动同步

`laws/` 按六类身份（在校大学生 / 劳动从业者 / 消费者 / 租客与房东 / 普通市民 / 银发长辈）组织法律法规与司法解释，目录见 `laws-catalog.json`（24 部，含《劳动法》《劳动争议调解仲裁法》《消费者权益保护法实施条例》《反电信网络诈骗法》《老年人权益保障法》《法律援助法》及劳动争议、网络消费、房屋租赁、民间借贷、婚姻家庭、人身损害、合同编通则等最高人民法院司法解释）。

自动同步机制（数据来源：[国家法律法规数据库 flk.npc.gov.cn](https://flk.npc.gov.cn/)）：

- `scripts/sync_laws.py --check`：按目录精确检索国家库，比对新版本（bbbs 变更即视为修订），供 CI 判断；
- `scripts/sync_laws.py --fetch`：同步元数据并尽力抓取全文（docx 解析为 txt），抓取失败时保留本地文本、状态写入 `laws-index.json`；
- `.github/workflows/sync-laws.yml`：每月 1 日自动同步，有变更即提交推送，报告见 `docs/laws-sync-report.md`；
- 国家库对海外 IP 可能限流，如 runner 拉取失败，可在具备公网条件的机器本地运行后推送。

> 提示：以最新法律法规为准；文本仅供公益普法学习。
