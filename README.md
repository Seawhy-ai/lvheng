# 律衡 · 全民法律知识普惠智能体

> 「律衡 — 全民法律知识普惠智能体」。基于团队自研 **LexPilot** 法律智能引擎，把「听得懂的解释 + 有依据的法条 + 可执行的指引」在网页上当场跑起来，面向公众免费开放。

西南民族大学 法学院 · 团队「舞猴」 · 参赛方向：社会公益（教育普惠 / 法律知识普惠）

## 这是什么

一个**零依赖单文件**网页应用（`index.html` 身份门 + `law.html` 真引擎，无任何 npm / 构建 / 后端步骤），直接部署到 GitHub Pages 即可访问。**「身份门」引导用户选择身份，内嵌并同源驱动真引擎**——能当场用真的题库判分、真翻法条与案例、真做学习时钟与笔记，而不仅仅是静态页。

设计继承 LexPilot 全套 UI 语言：

- 🎨 设计令牌同源：主色 `#1a5276` / 用户气泡 `#C5DFF8` / 金辉 `#f7b733`，卡片圆角 18px、微信式顶栏、深浅双主题
- 🐋 鲸鱼吉祥物与 `whaleFloat` 浮动动画
- 📱 响应式，移动端直开、适配手机

## 身份门（首页核心）

进入先问「你是谁」，五种身份对应项目书 **表3 目标用户画像**：

| 身份 | 图标 | 高频问题（内置静态普法速答） |
|---|---|---|
| 🎓 在校大学生 | 兼职·实习·校园贷 | 拖欠兼职工资 / 实习协议被扣押 |
| 💼 劳动从业者 | 劳动合同·欠薪·工伤 | 被无故辞退赔偿 / 拖欠工资追索 |
| 🛒 消费者 | 网购·线下·退赔 | 假货退一赔三 / 七天无理由 |
| 🏠 租客与房东 | 押金·合同·腾房 | 押金不退起诉 / 提前退租扣款 |
| 🧑‍🤝‍🧑 普通市民 | 婚姻·借贷·交通事故 | 无借条追债 / 交通事故流程 |

每身份都内置**静态普法速答**（结论 + 法条编号 + 操作建议 + 免责声明），**无需任何 API Key**、纯本地、立即可用。

## LIVE 在线体验（真引擎，不是截图）

页面内嵌同仓 `law.html`（同源）。身份门 JS **同源驱动** iframe：

- 点「AI 咨询」→ 把身份引导问题**预填进**引擎对话输入框（`contentWindow.enterChat()` + `#userInput.value`）
- 点「体验题库」→ 直接打开引擎「学习中心 → 题库」（`contentWindow.showLearningCenter()`）
- 题库判分 / 案例 / 法条为纯本地数据，无需配置即可用
- 跨域（本地预览）时自动降级为「新窗口打开」

## 快速开始

```bash
# 本地预览（任意静态服务即可，同源驱动即生效）
npx serve .
# 或 python -m http.server 8000
```

## 部署
