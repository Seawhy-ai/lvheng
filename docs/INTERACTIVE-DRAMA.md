# 法律互动剧场 · 第一集

《押金消失之后》为原创教学虚构的动态分镜互动故事，不是真人视频。玩家先选择行动，再查阅四类材料、作初判；照片时间无法核实后重新判断，最后换位为调解员并说明下一步。

- 分支：要求全退 / 索要明细 / 先调查，获得不同回应；换位选择影响片尾情境。
- 记录：实际打开的材料、初判、新信息后判断、理由、换位选择和下一步。不生成能力分数、胜诉概率或真实案件结论。
- 存档：`lvheng_drama_v1:<userId>`，自主与班级任务分别续玩，最多保留 12 次完成记录。浏览器清理数据会移除本地存档。
- 课堂：教师预览后发布，学生完成后主动提交；同班教师查看本集记录。重复发布和重复提交同一记录不会新增副本。
- 权限：后端检查角色、班级所有权、成员关系及归档状态，不信任客户端 studentId 或 score。
- 来源：法律学习参考为最高人民法院公布的民法典全文，第 710、711、733 条；本局材料、金额及人物为教学编写。
