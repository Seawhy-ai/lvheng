# 律衡决赛版升级说明

## 一、决赛定位

律衡从“法律问答网页”升级为“情境式法律素养教育智能体”。核心闭环为：问题诊断 → 事实补全 → 官方依据 → 行动模拟 → 情境练习 → 能力评价。

项目不替代律师提供个案法律意见，重点培养学习者的问题识别、事实提取、证据意识、法条检索和维权路径选择能力。

## 二、可演示创新点

1. 三套真实情境任务：大学生兼职欠薪、网购虚假宣传、租房押金不退。
2. 五维法律素养画像：完成任务后即时更新，并给出个性化建议。
3. 教师课堂看板：以匿名、本地汇总方式展示作答次数、正确率和任务完成情况。
4. 可信回答机制：事实先行、来源可溯、程序兜底、隐私透明。
5. 双路径可用：配置模型时提供大模型回答；未配置或网络异常时，本地知识库仍可工作。
6. 组委会FastGPT安全接入：浏览器只访问轻量代理，API密钥不进入网页源码或本地备份。

## 三、五分钟现场演示脚本

1. 进入主页，点击右下角“决赛学习中心”。
2. 选择“大学生兼职欠薪”，讲解事实要素和可信法律依据。
3. 完成情境判断，展示形成性反馈。
4. 进入“能力报告”，展示五维能力变化与个性化建议。
5. 进入“教师看板”，展示匿名课堂统计。
6. 返回AI咨询，输入“兼职两个月没发工资，也没签合同”。展示领域识别、具体法条、行动路径和强制免责声明。
7. 断开网络，演示本地FAQ、题库、法条和情境学习仍然可用。

## 四、评测口径

- `tests/`：39项工程回归断言，检查领域规则、FAQ、题库、案例、模板、安全后处理和离线资源一致性。
- `evaluation/`：与生产知识库分离的105条场景表达基线，用于复现领域识别准确率。
- 教育效果不得由工程测试替代。正式答辩数据应来自真实学习者的前测、后测、任务表现与匿名问卷。

## 五、数据与隐私

- 笔记、学习记录和能力报告默认仅保存在浏览器。
- 导出备份明确排除API密钥。
- 只有用户主动配置并调用大模型时，当前问题与必要的最近对话才会发送给模型服务商。
- 教师看板当前是单机匿名演示，不虚构跨学生、跨设备的云端统计能力。

## 六、答辩边界

目前使用可解释的关键词检索与结构化知识注入，不再表述为“向量RAG”。法规目录为24部；仓库包含其中部分全文，目录项和全文数量必须分别说明。项目总体积以发布时实测为准，不固定宣称3MB。
