# 律衡决赛版升级说明

## 一、决赛定位

律衡不是单独的法律问答或刷题工具，而是“基于大模型的法律素养教学管理平台”。管理对象包括教师、学生、班级、教学任务、学习过程和能力评价。

核心闭环：教师创建班级 → 发布情境任务 → 学生完成五步训练 → 系统记录与评价 → 班级学情聚合 → 教师调整教学。

## 二、系统组成

- 教师端：创建班级、生成邀请码、选择情境模板、保存草稿、发布任务、查看真实提交与五维班级能力。
- 学生端：输入班级码加入、接收已发布任务、完成五个能力环节、提交并查看反馈。
- 业务后端：Cloudflare Worker + D1，负责角色鉴权、权限隔离、班级、任务、提交和统计。
- AI服务：FastGPT负责辅助生成任务与教学分析；密钥只保存在Worker Secret中。
- 公众学习端：保留问题梳理、法条、案例、题库、文书和计算器，作为课程资源与自主学习工具。

## 三、五分钟现场演示

1. 教师登录，创建“大学生法律素养一班”，展示系统生成的6位班级码。
2. 教师选择“大学生兼职欠薪”五步情境模板，审核后发布。
3. 学生在另一部手机输入班级码加入，立即看到教师刚发布的任务。
4. 学生完成争议识别、事实梳理、证据固定、依据核验和路径选择并提交。
5. 教师端刷新，展示真实新增的提交、班级平均分、五维能力和相对薄弱点。
6. 说明FastGPT用于任务生成和教学建议，业务数据与规则评分不依赖FastGPT，因此临时密钥到期后核心管理功能仍可工作。

## 四、真实性原则

- 没有学生提交时，人数、提交数、平均分和能力值显示0或“—”。
- 同一学生对同一任务只能提交一次，避免重复刷分。
- 教师只能访问自己班级的数据；学生只能看到已加入班级的已发布任务。
- 单机演示模式有醒目标识，不把浏览器本地数据冒充云端班级数据。
- 教育效果必须通过真实学习者前后测和匿名问卷取得，工程测试不替代教育实证。

## 五、数据与隐私

- 密码使用PBKDF2-SHA256加盐哈希。
- 会话令牌在数据库中只保存SHA-256摘要。
- FastGPT API Key和教师注册码仅保存在Worker Secret。
- 只收集教学所需的昵称、班级、作答与能力结果，不要求手机号和身份证号。
- FastGPT不可用时，班级、任务、提交和确定性评分继续运行。

## 六、当前边界

正式跨设备运行必须部署Worker、创建D1并配置前端Worker地址。未绑定D1时只提供明确标注的单机演示。当前不接入学习通和希沃，不宣称尚未实现的平台集成能力。
