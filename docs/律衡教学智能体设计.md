# 律衡法律素养教学智能体设计

## 一、智能体定位

律衡智能体面向高校法律素养教育，连接教师教学设计、学生个性化学习和班级学情管理。它不代替教师评分、不代替律师提供法律意见，也不使用学生的私人自主问题监控学生。

## 二、三种工作模式

### 教师教学设计

输入教学目标、学习对象、课堂时长和难度，输出一个包含真实情境、五维问题、选项、答案、解析和教师提示的结构化草稿。草稿必须经过教师审核，不能由智能体直接发布。

### 学生学习陪练

理解学生的自然语言描述，判断当前学习阶段和缺失事实，一次只提出一个关键追问，同时给出法规检索范围、证据提示和递进行动。它提供学习支架，不直接替学生完成答案。

### 班级学情诊断

读取D1中真实提交形成的匿名化成绩与五维数据，输出共性发现、按学习需要划分的学生组和下一课干预建议。没有真实提交时明确返回“暂无数据”，不得虚构分析。

## 三、系统边界

| 层级 | 职责 |
|---|---|
| FastGPT | 自然语言理解、任务草稿、动态追问、学情解释 |
| Worker | 身份鉴权、权限校验、数据脱敏、提示词编排、输出校验 |
| D1 | 班级、任务、成员、提交与评分记录 |
| 规则引擎 | 客观题评分和五维确定性计算 |
| 教师 | 审核任务、确认评价与教学干预 |

## 四、工作流

教师目标 → 智能体生成草稿 → 教师审核发布 → 学生完成任务或接受陪练 → 后端保存真实任务提交 → 智能体分析匿名学情 → 教师确认干预 → 形成下一轮任务。

## 五、安全机制

- API Key只放在Worker Secret，不进入网页和GitHub仓库。
- 学生自主学习文本不写入班级学情数据库。
- 班级诊断不向模型发送学生姓名，只发送任务名称、总分和五维分数。
- 大模型输出必须解析为JSON并通过长度、题量、能力维度和答案范围校验。
- AI生成内容标记来源和“需教师审核”，不能自动发布或直接修改成绩。
- FastGPT不可用时，系统显示本地示范能力，班级、任务、规则评分和报告继续工作。

## 六、FastGPT建议节点

身份与意图识别 → 输入安全检查 → 角色提示词 → 法规/教学知识库检索 → 大模型生成 → JSON结构化 → 法条与敏感信息校验 → Worker业务接口 → 前端展示与教师审核。
