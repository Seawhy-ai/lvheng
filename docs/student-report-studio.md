# 学生学习实验室

- 学情总览：正式班级成绩、五维平均表现、按实际错题比例排序的维度线索，以及最近任务成绩变化。少于两次任务不画趋势，缺失维度不补零。
- 判断复盘：原选择、参考答案、解析、学生自主归因，以及事实—证据—依据—结论四步复盘。条件变更推演由学生填写，不生成未经验证的“裁判结果”。
- 迁移记录：沿用已有相似题接口，每题必须先选答案和信心程度。记录“很有把握但答错”的作答并与原题状态并列展示，不将两种难度不同的题目直接相减为“提升率”。
- 复盘与迁移记录按账号保存于本设备 localStorage；最多200条复盘和60次练习，不上传教师端。记录写入失败明确提示。正式班级分数不受影响。
- 沿用 /api/student/report 与 /api/student/similar-practice，无新增后端接口。缺少逐题记录的旧报告仍展示已有考点分析。

测试覆盖：桌面/手机、缺失数据、刷新保留、账号隔离、HTML转义、信心校准、旧报告兼容、既有学生/教师备课流程。
