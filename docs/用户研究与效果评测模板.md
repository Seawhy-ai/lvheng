# 用户研究与教育效果评测模板

> 本文件是决赛前开展真实测试的执行模板，不包含虚构结果。

## 研究设计

- 建议样本：30—60名学习者；尽量覆盖法学与非法学专业。
- 流程：知情说明 → 前测 → 使用律衡完成指定情境任务 → 后测 → 匿名问卷。
- 前后测使用难度相当但题目不同的平行测试，避免记忆效应。

## 核心指标

| 指标 | 计算方式 |
|---|---|
| 法律问题识别率 | 正确识别领域人数/总人数 |
| 关键事实完整率 | 正确列出的关键事实/标准事实总数 |
| 证据清单完整率 | 正确选择的证据项/标准证据项 |
| 维权路径正确率 | 正确选择渠道与顺序人数/总人数 |
| 学习增益 | 后测得分－前测得分 |
| 任务完成时间 | 从任务开始到提交的分钟数 |

## 问卷建议

采用5级量表：内容易懂、依据可信、步骤可执行、愿意继续使用、愿意推荐；另设开放题“最有帮助之处”和“最需要改进之处”。

## 报告要求

报告样本量、均值、标准差和前后测差异；原始记录去标识化保存。没有完成真实测试前，不得在答辩材料中宣称教育效果显著。
