# 律衡——全民法律知识普惠智能体

## 项目概要介绍

### 一、项目介绍

律衡是一款面向普通公众的免费法律知识普惠智能体，由西南民族大学法学院「舞猴」团队自主研发，参加 AI 智能体大赛社会公益方向。它把「听得懂的法律解释＋有依据的法条引用＋可执行的维权指引」融为一体，通过公开网页即可访问，浏览器直开、零下载零安装，降低公众获取法律知识的门槛，助力教育普惠。项目以团队自研 LexPilot 法律智能引擎为技术底座，采用零依赖单文件网页应用形态，数据存本机不落服务器，支持离线可用，源码与知识库全部开源。线上体验：https://seawhy-ai.github.io/lvheng/（GitHub：Seawhy-ai/lvheng）。

### 二、核心功能

1. **AI 法律对话**：基于国产大模型的生活场景问答，回答统一为「通俗结论＋法条引用＋操作建议」三件套；
2. **领域自动识别**：自动识别劳动、消费、婚姻、房产、借贷、交通等领域并分流到对应知识库；
3. **案情要素引导**：多轮追问合同、在职状态等关键事实，会话内记忆，输出精准指引；
4. **维权路径指引**：按领域输出仲裁/投诉/诉讼渠道、流程与材料清单；
5. **文书模板与普法案例**：内置借条、合同要点等模板与问答式案例普法；
6. **免责与转介**：回答自动附带免责声明，重大事项强制引导 12348 与法律援助；
7. **普法学习工具**：法条/案例/题库检索、考试判分、笔记与学习打卡；
8. **多入口多端访问**：分享链接、网页嵌入、二维码，桌面与移动端响应式适配。

### 三、技术路线

采用「入口层—表现层—应用层—数据与 AI 层」四层架构。入口层承载链接、嵌入、公众号菜单、二维码多渠道访问；表现层为单文件 Web 应用（HTML/CSS/JS），多视图导航、皮肤主题、响应式适配；应用层自研实现对话、分流、指引、检索、判分等能力；数据与 AI 层使用 localStorage 本地存储＋Service Worker 离线缓存（PWA）＋国产低成本大模型 API，依托「法条、案例、FAQ、渠道、模板」五类知识库分库，采用关键词＋向量混合检索、Top-K 控制与来源标注保证可溯。法律资源库经 GitHub Actions 每月自动同步国家法律法规数据库（30+ 部法规，含 2025 新修订版本校验），支持 GitHub Pages 免费静态托管。

### 四、预期成果

建成免费可访问的公益普法智能体（应用体积约 3MB）：30+ 部法规与司法解释入库、30+ 高频场景、10 项核心功能全部落地；100+ 条测试集通过率 ≥90%、领域识别正确率 ≥95%、法条引用准确率抽查 100%、免责/转介覆盖率 100%、单轮问答 ≤8 秒；发布可复现测试基线（36 项自动化断言）；LexPilot 引擎与知识库模板开源，任何高校、社区可一键复刻本地版普法智能体，形成可推广的公益普法范式。

### 五、创新性说明

1. **自研零依赖单文件引擎**：无需安装、数据存本机、对话不落服务器，隐私防护优于服务端落库方案，静态托管零成本；
2. **「结论—依据—行动—边界」四字段回答结构**：先大白话、再法条编号、后分步操作、终免责转介，兼顾通俗与严谨；
3. **合规业务规则红线的工程化落地**：仅普法不替代律师、法条必须可溯、刑事/重大纠纷强制转介、不采集敏感信息，以提示词约束＋测试集把关双重保障；
4. **五库分领域知识库＋RAG 混合检索**：领域隔离防串场，法条修订自动同步，回答可溯源、可验证；
5. **公益导向的开源闭环**：源码与知识库全开源，学-练-赛闭环开发，公益价值与技术能力并重。

### 六、应用价值说明

面向在校大学生、劳动从业者、消费者、租客房东、普通市民五类人群，覆盖兼职欠薪、租房押金、消费维权、工伤赔偿、民间借贷、交通事故等高频生活纠纷场景。公众可免费获得「听得懂、有依据、可执行」的法律指引，对接 12348/12315/12333 公共维权资源形成「普法—指引—转介」公益闭环，缓解专业法律咨询成本高、公益资源不足的问题；以网页形态零成本部署、全天候开放，并在高校与社区开源复刻，推动法律知识走进日常生活，服务法治社会与教育普惠建设。
