# 律衡——全民法律知识普惠智能体

## 项目概要介绍

### 一、项目介绍

律衡是一款面向普通公众的情境式法律素养教育智能体，由西南民族大学法学院「舞猴」团队自主研发。它把「听得懂的解释＋有依据的法条＋可执行的训练任务」融为一体，通过公开网页即可访问。学习记录默认存于本机；只有用户主动启用大模型咨询时，必要对话才会发送给模型服务商。项目支持离线使用，源码与知识库全部开源。线上体验：https://seawhy-ai.github.io/lvheng/（GitHub：Seawhy-ai/lvheng）。

### 二、核心功能

1. **AI 法律对话**：基于国产大模型的生活场景问答，回答统一为「通俗结论＋法条引用＋操作建议」三件套；
2. **领域自动识别**：自动识别劳动、消费、婚姻、房产、借贷、交通等领域并分流到对应知识库；
3. **案情要素引导**：多轮追问合同、在职状态等关键事实，会话内记忆，输出精准指引；
4. **维权路径指引**：按领域输出仲裁/投诉/诉讼渠道、流程与材料清单；
5. **文书模板与普法案例**：内置借条、合同要点等模板与问答式案例普法；
6. **免责与转介**：回答自动附带免责声明，重大事项强制引导 12348 与法律援助；
7. **普法学习工具**：法条/案例/题库检索、考试判分、笔记与学习打卡；
8. **多入口多端访问**：分享链接、网页嵌入、二维码，桌面与移动端响应式适配。

### 三、技术路线

采用「入口层—表现层—应用层—数据与 AI 层」四层架构。应用层实现对话、分流、情境任务、形成性评价、检索和判分；数据与 AI 层使用 localStorage、本地知识库、Service Worker 与可选的大模型 API。目前采用可解释关键词检索和结构化知识注入，并展示来源；法律目录收录24部法规与司法解释，由 GitHub Actions 定期检查国家法律法规数据库版本。

### 四、预期成果

建成免费可访问的公益法律素养教育智能体：24部法规与司法解释目录、30+高频场景、三套情境任务和五维能力评价；发布39项工程回归断言与105条独立领域识别评测表达。准确率、学习增益与响应时间均以可复现实测结果为准，不以工程断言替代真实教育效果研究。

### 五、创新性说明

1. **自研零依赖网页引擎**：无需安装，学习数据默认存本机；启用AI咨询时透明说明必要对话将发送至模型服务商，静态托管零成本；
2. **「结论—依据—行动—边界」四字段回答结构**：先大白话、再法条编号、后分步操作、终免责转介，兼顾通俗与严谨；
3. **合规业务规则红线的工程化落地**：仅普法不替代律师、法条必须可溯、刑事/重大纠纷强制转介、不采集敏感信息，以提示词约束＋测试集把关双重保障；
4. **五库分领域知识库＋可解释检索**：领域隔离防串场，法条版本定期核验，回答展示来源；后续可在具备服务端能力时扩展向量检索；
5. **公益导向的开源闭环**：源码与知识库全开源，学-练-赛闭环开发，公益价值与技术能力并重。

### 六、应用价值说明

面向在校大学生、劳动从业者、消费者、租客房东、普通市民五类人群，覆盖兼职欠薪、租房押金、消费维权、工伤赔偿、民间借贷、交通事故等高频生活纠纷场景。公众可免费获得「听得懂、有依据、可执行」的法律指引，对接 12348/12315/12333 公共维权资源形成「普法—指引—转介」公益闭环，缓解专业法律咨询成本高、公益资源不足的问题；以网页形态零成本部署、全天候开放，并在高校与社区开源复刻，推动法律知识走进日常生活，服务法治社会与教育普惠建设。
