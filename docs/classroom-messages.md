# 师生消息与改名审批 · 2026-10-26

入口：教师和学生登录后，顶部「消息」。师生会话支持聊天、教师学习点评、未读提醒和更早消息；每 12 秒刷新。联系人限定为当前未归档班级的师生，不支持学生之间互聊。

学生在「个人资料」填写新姓名并保存，姓名保持原值；由所属班级教师在「消息 → 改名申请」同意或拒绝。多个任课教师时默认交给联系人排序第一位教师。学号独立保存，登录账号不会改变。
